# DropShare 文件快传

**端到端加密 · 无需登录 · 即用即焚**

安全无登录的文件互传工具。文件在浏览器中用 AES-256-GCM 加密后上传，服务器只存储密文，无法读取文件内容。

---

## 访问地址

```
电脑/手机： https://8.163.102.28:3443
本机调试：   http://localhost:8080
```

> 第一次访问 HTTPS 会提示"连接不安全"——自签名证书无法被浏览器信任，但通信本身是加密的。点击**「高级 → 继续访问」**即可。

---

## 使用方法

### 发送文件

1. 打开访问地址
2. 切换到 **「发送文件」** 标签
3. 拖拽或点击选择要发送的文件（最大 5GB）
4. 可选设置：
   - **加密密码**：不设密码则自动生成密钥嵌入分享链接；设密码则接收方需输入密码解密
   - **过期时间**：1小时 / 6小时 / 24小时 / 7天
5. 点击 **「上传并生成分享链接」**
6. 分享方式：
   - **复制链接**：发给对方
   - **二维码**：让对方扫码打开

### 接收文件

**方式一：直接点分享链接**

```
https://8.163.102.28:3443/dl/abc123#密钥
```

浏览器自动进入接收模式，点击「解密并下载」即可。

**方式二：手动输入**
1. 切换到 **「接收文件」**
2. 粘贴完整分享链接或输入分享码
3. 如有密码保护则输入密码
4. 点击 **「解密并下载」**

## 部署说明

### 环境要求

- Node.js 18+
- npm
- OpenSSL（用于生成自签名证书）

### 本地运行

```bash
cd dropshare
npm install
npm start
```

### 云服务器部署（2核2G 优化配置）

1. 将项目上传到服务器
2. 配置 `.env` 文件
3. 安装依赖并启动：

```bash
npm install
npm install -g pm2
pm2 start ecosystem.config.js   # 使用资源配置文件
pm2 save
pm2 startup
```

4. 阿里云安全组入方向放行：
   - `TCP 3443`（HTTPS 文件互传）
   - `TCP 8080`（HTTP，可选调试用）

### 管理命令

```bash
pm2 status                 # 查看运行状态
pm2 logs dropshare         # 查看日志
pm2 restart dropshare      # 重启
pm2 stop dropshare         # 停止
pm2 restart ecosystem.config.js  # 更新配置后重载
```

## 资源限制说明

针对 2核2G 云服务器已做以下优化：

| 限制项 | 配置值 | 说明 |
|--------|--------|------|
| 最大文件 | 5GB | 单次上传文件上限 |
| 内存上限 | 1.5GB | 超出自动重启进程 |
| 运行模式 | 单进程 fork | 比 cluster 模式省一半内存 |
| 上传频率 | 30次/15分钟 | 防止并发过多导致 OOM |
| 下载频率 | 100次/15分钟 | 同上 |
| 日志大小 | 100MB 轮替 | 防止日志撑爆 40GB 磁盘 |

## 配置文件说明 (`.env`)

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | `8080` | HTTP 服务端口 |
| `HTTPS_PORT` | `3443` | HTTPS 服务端口 |
| `UPLOAD_DIR` | `./uploads` | 文件存储目录 |
| `MAX_FILE_SIZE` | `5368709120` | 最大文件大小（字节，5GB） |
| `CORS_ORIGIN` | `*` | 跨域来源 |
| `PUBLIC_URL` | `https://8.163.102.28:3443` | 公网地址 |
| `TRUST_PROXY` | `false` | 是否在反向代理后方 |
| `UPLOAD_MAX` | `30` | 每15分钟最大上传次数 |
| `DOWNLOAD_MAX` | `100` | 每15分钟最大下载次数 |

## 安全说明

- **端到端加密**：文件在浏览器中用 AES-256-GCM 加密，服务器只存密文
- **无密码模式**：密钥嵌入 URL 的 `#hash` 中，不经过网络传输
- **密码模式**：PBKDF2 600000 次迭代派生密钥
- **自动过期**：到期后服务器自动删除文件
- **频率限制**：防止滥用
- **内存保护**：超 1.5GB 自动重启

---

## 技术栈

- **后端**：Node.js + Express
- **前端**：原生 JavaScript + Web Crypto API
- **加密**：AES-256-GCM + PBKDF2
- **进程管理**：PM2 + ecosystem.config.js
